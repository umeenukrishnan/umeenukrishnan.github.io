Preprint arXiv:2611.23682 · November 2026

Axion: A differentiable, GPU-native finite element framework, demonstrated on phase-field fracture

Wei Wang, Meenu Krishnan U., Somdatta Goswami

Axion (Autodifferentiable, XLA-compiled, Implicit, On-device Numerics) is a finite element framework written in JAX. The element kernels, Newton and Krylov iterations, bound-constrained updates, staggered coupling of fields and the loop over load increments are expressed as a single program that is just-in-time compiled and runs on the GPU without host intervention.

Consistent tangents come from forward-mode automatic differentiation of the element residual, and derivatives of the solution with respect to model parameters come from differentiating the same program. Operators are applied element by element without assembling a sparse matrix, octree refinement lives in fixed-size arrays, and a cell-based domain decomposition runs the same program on several GPUs. Phase-field fracture is the first module.

  • 37.9×faster than FEniCSx, one GPU vs one CPU (2D tension benchmark)
  • 92% / 96%strong / weak scaling on four GPUs
  • 96M DOFconcrete gravity dam on a single GPU

Preprint arXiv:2611.03473 · November 2026

Fracture-Bench: A Controlled Benchmark Suite for Machine Learning Surrogates in Phase-Field Fracture Mechanics

Meenu Krishnan U., Maryam Hakimzadeh, Indrashish Saha, Meer Mehran Rashid, Lori Graham-Brady, Somdatta Goswami

Which neural surrogates can you trust to replace phase-field fracture simulations, for which problems, and how far beyond their training data? Fracture-Bench is an open benchmark of two phase-field datasets with fixed splits, common test metrics and a description of each dataset’s physical regime. A Fourier neural operator (FNO), DeepONet, Latent DeepONet, a UNet and a conditional diffusion model are trained on identical splits and compared on accuracy, training time, inference time and model size.

Dataset 1 · 1,000 AT2 simulations

Multiple cracks growing from a notched hole in a hyperelastic plate under random non-uniform biaxial boundary displacements (44 load steps, 128×128 grid).

Dataset 2 · 4,000 PF-CZM simulations

A pre-cracked plate with two inclusions, each ten times stiffer or more compliant than the matrix (128×256 grid).

  • 10−6mean test error of FNO and Latent DeepONet on Dataset 1, about 10× below UNet and DeepONet
  • 706 s vs 6 msper prediction on Dataset 2: the diffusion model is most accurate (about one sixth of the UNet error), but far slower than UNet
  • Final stepsmost of the error appears after crack localization, so rankings depend on the task

Data, codes, splits, regime descriptors and generalization splits are public, with a protocol for adding under-represented regimes such as mixed-mode, three-dimensional and experimentally paired fracture.
